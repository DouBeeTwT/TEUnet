# TEUnet: An Entropy-guided Edge Enhancement U-net for Segmentation in Medical Images with Blurred Edges

Official implementation of **TEUnet**, a deep learning segmentation framework engineered to enhance edge boundary definition in medical imaging through entropy-guided attention mechanisms.
